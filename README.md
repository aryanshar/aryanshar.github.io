Static portfolio

This repository now contains a minimal single-page static portfolio (plain HTML + CSS).

Files of interest:

- `index.html` — main single-page site
- `css/styles.css` — stylesheet
- `assets/` — place `resume.pdf` and images here (see `assets/README.md`)

To preview locally you can use a simple static server, for example with Python 3:

```bash
python3 -m http.server 4000

# then open http://127.0.0.1:4000
```
